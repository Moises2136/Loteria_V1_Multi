🎴 Lotería Mexicana Multijugador
Proyecto desarrollado en Unity que recrea el clásico juego de la Lotería Mexicana con soporte multijugador.

📌 Descripción
Esta aplicación permite a varios jugadores participar en partidas de Lotería Mexicana de manera simultánea. El proyecto fue desarrollado como práctica de desarrollo de videojuegos usando Unity, aplicando conceptos de UI, gestión de estados de juego, networking y experiencia de usuario.

✨ Características
Sistema de cartas aleatorias.
Tableros de juego interactivos.
Interfaz desarrollada con Unity UI Toolkit.
Soporte para partidas multijugador.
Pantallas de inicio, juego y créditos.
Gestión de victoria y verificación de tablero.
